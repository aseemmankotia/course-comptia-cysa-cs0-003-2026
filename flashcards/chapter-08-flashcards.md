## Chapter 8: Incident Response: Attack Frameworks and Core IR Activities — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | List the 7 Cyber Kill Chain phases in order. | Reconnaissance → Weaponization → Delivery → Exploitation → Installation → Command and Control → Actions on Objectives. Exam tip: breaking any link earlier in the chain is cheaper/more effective defense. |
| 2 | What are the 4 core features (vertices) of the Diamond Model of Intrusion Analysis? | Adversary, Capability, Infrastructure, Victim — arranged in a diamond and connected by an event. Exam tip: meta-features (Timestamp, Phase, Result, Direction) describe the event itself. |
| 3 | Diamond Model: which vertex covers malware, exploits, and tools used by the attacker? | Capability. Infrastructure covers the delivery mechanism (IPs/domains); Capability covers what the adversary uses to exploit the victim. |
| 4 | How many phases make up the NIST SP 800-61 Incident Response Life Cycle? | 4: Preparation; Detection and Analysis; Containment, Eradication, and Recovery; Post-Incident Activity. Exam tip: CS0-003 groups Containment/Eradication/Recovery as one combined phase. |
| 5 | Short-term containment vs long-term containment — what's the key difference? | Short-term: immediate action to stop spread (isolate host, block IP/VLAN) without full remediation. Long-term: temporary fixes (patches, rule changes) applied to affected systems while preparing for full eradication/recovery. |
| 6 | Correct order: Containment, Eradication, Recovery — what happens in each? | Containment = stop spread; Eradication = remove root cause (malware, backdoors, vulnerable configs); Recovery = restore systems to normal operation and monitor for reinfection. |
| 7 | How many tactics are in the current MITRE ATT&CK Enterprise matrix? | 14 tactics (Reconnaissance, Resource Development, Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, Command and Control, Exfiltration, Impact). |
| 8 | MITRE ATT&CK vs Cyber Kill Chain — when does the exam prefer each? | Use Kill Chain for high-level attack progression/sequencing questions. Use ATT&CK for granular technique mapping, detection engineering, and threat hunting questions (technique IDs like T1566). |
| 9 | What does OWASP Top 10 provide, and what edition is current as of 2026? | A ranked list of the most critical web application security risks (e.g., Injection, Broken Access Control) with remediation guidance. Current edition: 2021 release, still the reference standard as of 2026. |
| 10 | Order of Volatility (RFC 3227) — what's collected first? | CPU registers/cache → routing table/ARP cache/process table → RAM → temp file systems → disk → remote logs/monitoring data → physical config/network topology → archival media. Exam tip: most volatile evidence collected first. |
| 11 | Precursor vs Indicator in incident detection — what's the difference? | Precursor: a sign an incident MAY occur in the future (e.g., new exploit announced, scanning activity). Indicator: a sign an incident HAS occurred or is occurring (e.g., alert triggered, unusual traffic). |
| 12 | Detection and Analysis phase — what key output must be determined before Containment begins? | Scope and impact of the incident (affected systems, data sensitivity, business criticality) — used to prioritize response before selecting a containment strategy. |
