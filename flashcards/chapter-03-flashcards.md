## Chapter 3: Security Operations: Threat Intelligence, Threat Hunting, and MITRE ATT&CK — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | How many Tactics exist in the MITRE ATT&CK Enterprise Matrix? | 14 tactics (e.g., Initial Access, Execution, Persistence, Exfiltration, Impact). Exam tip: Tactics answer 'why' (the objective); Techniques answer 'how'. |
| 2 | What are the 6 phases of the Intelligence Cycle, in order? | Direction → Collection → Processing → Analysis → Dissemination → Feedback. Exam tip: Feedback loops back into Direction, making it cyclical, not linear. |
| 3 | IOC vs TTP — core exam distinction? | IOC = atomic artifact of a past attack (hash, IP, domain) — easy for attacker to change. TTP = behavioral pattern of HOW an actor operates — hard for attacker to change. Exam tip: TTP-based detection survives infrastructure changes; IOC-based does not. |
| 4 | OSINT vs ISAC vs Commercial Feed — when to use each? | OSINT = free, public, unvetted (blogs, forums). ISAC = sector-specific, peer-vetted, shared among member orgs in same industry. Commercial Feed = paid, broad or curated, vendor-analyzed. Exam tip: sector-specific requirement in a scenario → answer is ISAC. |
| 5 | Nation-state actor vs Hacktivist — motivation difference? | Nation-state = espionage/strategic advantage, high resources, long dwell time, often uses zero-days. Hacktivist = ideological/political disruption, seeks publicity, lower sophistication. Exam tip: 'long-term stealth + espionage' = nation-state; 'defacement + public statement' = hacktivist. |
| 6 | Insider threat vs Cybercriminal — key difference tested on exam? | Insider = already has legitimate access, motive can be revenge/financial/ideological. Cybercriminal = external, financially motivated, must gain access via exploitation. Exam tip: scenario with no external intrusion evidence but data leaves via authorized account = insider. |
| 7 | List the 6 STRIDE threat categories. | Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege. Exam tip: match the threat description to the category — 'altering data in transit' = Tampering, 'denying an action occurred' = Repudiation. |
| 8 | What are the core steps of hypothesis-driven threat hunting? | 1) Form a hypothesis (often from ATT&CK/threat intel) 2) Identify data sources/telemetry needed 3) Investigate/query for evidence 4) Uncover new patterns or confirm/refute hypothesis 5) Inform detection improvements. Exam tip: hunting is PROACTIVE, starting from a hypothesis, not from an alert. |
| 9 | What is the structure of an Attack Tree? | Root node = attacker's ultimate goal; branch/leaf nodes = individual steps/methods to achieve that goal, often with AND/OR logic. Exam tip: used for threat modeling to visualize multiple attack paths to one objective, distinct from STRIDE's category-based approach. |
| 10 | MITRE ATT&CK ID numbering: What does 'T1566.001' represent vs 'T1566'? | T1566 = Technique (Phishing). T1566.001 = Sub-technique (Spearphishing Attachment) — the '.001' suffix denotes a sub-technique of the parent technique. Exam tip: sub-techniques always use a decimal suffix on the parent technique ID. |
| 11 | MITRE ATT&CK ID prefixes: What do 'TA' and 'T' prefixes mean? | TA#### = Tactic ID (e.g., TA0001 = Initial Access). T#### = Technique ID (e.g., T1566 = Phishing). Exam tip: 'TA' = Tactic, plain 'T' = Technique — don't confuse the two on ID-matching questions. |
| 12 | What is the Pyramid of Pain and its order (bottom to top)? | Hash Values → IP Addresses → Domain Names → Network/Host Artifacts → Tools → TTPs. Exam tip: the higher on the pyramid, the more 'pain' it causes an attacker to change — detecting on TTPs (top) is most disruptive to the adversary. |
