# Chapter 6 Lab: Vulnerability Management: Analyzing and Prioritizing Vulnerability Data

**Estimated time:** 25 minutes

## Exercise

Given a scan report with three findings of differing CVSS scores and exposure levels, rank them for remediation priority using context, not raw CVSS score alone.

## Key takeaway

CVSS score is a starting point, not the final answer — exploitability, exposure, and asset value determine true remediation priority.
