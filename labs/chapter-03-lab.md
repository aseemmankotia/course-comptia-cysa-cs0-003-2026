# Chapter 3 Lab: Security Operations: Threat Intelligence, Threat Hunting, and MITRE ATT&CK

**Estimated time:** 20 minutes

## Exercise

Map a described attacker behavior (credential dumping via LSASS access) to the correct MITRE ATT&CK tactic and technique, then write a one-sentence hunt hypothesis to search for it in endpoint logs.

## Key takeaway

TTPs describe attacker behavior and persist across campaigns, making them far more durable hunting leads than perishable IOCs.
