# Chapter 1 Lab: Security Operations: System and Network Architecture Concepts

**Estimated time:** 20 minutes

## Exercise

Walk through a sample SIEM architecture diagram and map log sources (firewall, endpoint, auth server) to ingestion pipelines; identify where a DLP alert would trigger.

## Key takeaway

Security operations start with knowing what data sources exist, where they live, and how they reach the SIEM — architecture gaps are exam-favorite scenarios.
