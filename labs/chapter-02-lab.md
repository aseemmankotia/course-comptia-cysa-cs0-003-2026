# Chapter 2 Lab: Security Operations: Detecting Malicious Activity with SIEM, Logs, and Packet Data

**Estimated time:** 25 minutes

## Exercise

Analyze a sample raw log excerpt (failed logins, a successful login from a new geolocation, and an outbound connection to a rare external IP) and determine which single data source best confirms the attack chain.

## Key takeaway

Choosing the correct tool or data source for a given indicator — not memorizing tool names — is what the exam actually tests.
