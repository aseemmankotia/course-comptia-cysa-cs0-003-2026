# Chapter 10 Lab: Reporting and Communication: Vulnerability Management Reporting

**Estimated time:** 15 minutes

## Exercise

Given raw scan findings, draft a two-sentence executive summary for leadership versus a detailed technical remediation ticket for IT operations, using the same underlying data but different audience framing.

## Key takeaway

The same vulnerability data must be reframed for each audience — executives need risk and trend, engineers need exact remediation steps.
